# 搬运溯源 v2 设计（drama_trace_v2）

> 基于 P0 189 条字幕实证重新设计。原 v1 查不到的原因：依赖 yt-dlp 向外搜索中文频道，
> 但搬运剧标题/描述已本地化，中文原名只在字幕内容层残留，向外搜必然失配。

## 一、为什么 v1 查不到（根因）

| v1 依赖 | 为什么失败 |
|---|---|
| ytsearch 搜中文剧名 | 搬运频道标题已本地化（印尼语/西语/日语），中文原名不在标题/描述里 |
| 本地繁中池互查 | 竞品库繁中池未必收录同一部剧的原版 |
| bai 猜中文剧名 | 无内容证据约束，猜中概率低 |

**核心盲区：v1 在"标题层"找中文，但中文母本线索只存在于"字幕内容层"（角色名音译残留、华裔姓氏、剧情结构指纹）。**

## 二、P0 数据验证的事实

- 189 条中 **169 条 (89%) 是翻译剧**（origin_signals.feels_translated）
- **72/189 (38%) 含华裔姓氏音译角色名**（Zong/Chan/Lin/YeMing/Chandra 等）→ 中文母本强信号
- **16 组跨语种指纹聚类**（同一题材+剧情结构在多语种重复出现）→ 可识别"同一部剧被搬到多个语种"

## 三、新设计：三层证据链（不再依赖向外搜索）

```
输入: video_id 或 字幕分析结果(analysis dict)
   │
   ├─ 层1 翻译判定  origin_signals.feels_translated + reason
   │      非翻译剧 → 直接标记"本地原创/俄剧西配等"，溯源终止
   │
   ├─ 层2 中文信号提取（字幕内容层）
   │      a) 华裔姓氏音译 → 中文姓氏候选（Zong→宗, Chan→陈, Lin→林, YeMing→叶明）
   │      b) 角色名音译还原 → bai 猜中文原名（喂 characters + distinctive_lines）
   │      c) 中文剧名还原 → bai 喂 synopsis+题材+姓氏信号 → 中文剧名候选+置信度
   │
   ├─ 层3 本地跨语种指纹聚类（核心新增）
   │      把库内所有视频按 题材L1×剧情结构指纹 聚类
   │      目标视频指纹 → 找同指纹的跨语种姊妹版（"这部剧也被搬到了 en/id/tr..."）
   │
   └─ 输出: 中文母本候选 + 跨语种姊妹版本 + 置信度
            未命中 → 人工辅助包（红果App搜索词）
```

## 四、与 v1 的本质区别

| 维度 | v1 | v2 |
|---|---|---|
| 主路径 | 向外搜（yt-dlp） | 向内聚（本地指纹）+ 内容信号还原 |
| 依赖 | 网络 + 中文频道存在 | 字幕内容 + 库内数据（零网络） |
| 关键信号 | 标题/描述 | 角色名音译残留 + 华裔姓氏 + 剧情指纹 |
| 输出 | 单一中文剧名 | 中文母本 + 跨语种姊妹版 + 置信度 |
| 失败兜底 | manual_pack | 同（保留） |

## 五、产出

- 单视频溯源: `data/drama_trace/{video_id}.json`（v2 schema）
- 搬运雷达: 聚合所有溯源结果 → "哪些中文剧被搬到哪些语种、效果如何"
- 复用 l1_calibration/common.py 的 call_bai（零新增依赖）
